# 真题工场 · 校地协同任务实践平台（前端原型 V0.2）

> 私有仓库：`School-Enterprise-Platform`  
> 内部需求、汇报材料、测试截图与截图工具不纳入本仓库。

纯静态前端原型，用于向导师演示平台定位、核心流程与支付收款功能。
所有数据均为模拟数据，不会产生真实账号、交易或资金流转。
前端统一放在 `public/`，后续后端将放在 `server/`，共用同一个仓库。

## 启动预览

在项目根目录执行：

```powershell
node scripts/serve-static.js
```

浏览器打开：<http://127.0.0.1:5173>

也可以直接双击 `public/index.html` 打开，但建议使用本地服务器，避免部分浏览器对本地文件限制。

## 目录结构

```text
public/                 前端（Web 根目录）
  index.html
  assets/
scripts/
  serve-static.js       仅本地预览用的静态服务器
server/                 预留：后续后端
docs/internal/          内部资料（不提交）
```

## 推荐演示路径

1. 首页 → 四个入口：浏览在架真题 / 我要接项目 / 我要做审核 / 我要发任务。
2. 登录页 → 学生演示账号 → 工作台查看项目进度、里程碑与待办。
3. 「浏览在架真题」查看全部任务；「我要接项目」只显示可申请项目（`tasks.html?mode=recruit`）。
4. 「我要做审核」→ 未登录先登录 → 导师演示账号 → 匿名审核工作台；学生姓名、学号、联系方式、团队名称已隐藏。
5. 「我要发任务」→ 未登录先登录 → 企业演示账号 → 四步发布向导（可点 AI 生成六要素草案）→ 提交审核。
6. 学生/导师直接访问发布页会看到权限提示，不展示表单；企业可正常填写。
7. 资金中心 → 收银台 → 选择支付方式 → 确认支付 → 查看电子回单。
8. 资金中心 → 账单流水 / 收款与结算 / 发票管理。
9. 运营后台 → 任务审核（通过/驳回）→ 用户管理 → 财务对账 → 操作日志。

> 首页及公开页面中的站内跳转默认在新标签页打开；工作台、审核、资金、后台等重操作页面保留当前标签页跳转。

## 页面清单

页面均位于 `public/`：

- `index.html` 首页（三方关系图 + 四个入口）
- `login.html` 登录
- `register.html` 注册（三步向导）
- `tasks.html` 任务市场（`?mode=recruit` 为可申请项目模式）
- `task.html` 任务详情与认领
- `review.html` 匿名审核工作台（导师 / 运营）
- `publish.html` 企业发布任务（含身份守卫）
- `workspace.html` 四角色工作台
- `payment.html` 资金中心（收银台、账单、结算、发票）
- `admin.html` 运营后台

## 后续后端

- 后端代码放在 `server/`，通过 `/api` 提供接口，并托管 `public/` 静态文件。
- 前端将新增统一的 API 客户端，逐步替换 [data.js](public/assets/js/data.js) 和 localStorage 模拟数据。
- 正式版需要补充：统一身份认证、RBAC 权限、任务与里程碑数据库、支付机构分账接口、文件上传与审计日志。
- 当前前端权限守卫 [guard.js](public/assets/js/guard.js) 仅用于演示，真实权限必须由后端校验。
